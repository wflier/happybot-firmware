# Security policy

HappyBot firmware follows Cyberdyne standard **CYB-SEC-STD-014** (owner: Dr. Laurent Biegler).

- Only firmware signed by the Cyberdyne signing service may be released.
- Report vulnerabilities to the security contact, Lena Vos. Critical issues are patched within 30 days (SEC-08).
- A software bill of materials (SBOM) is published with every release (SEC-06).
