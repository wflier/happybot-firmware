# happybot-firmware

Firmware for **HappyBot 4.0 Secure**, the first joint product of Cyberdyne Systems and Sirius Cybernetics (Project Symbiosis). Fictional demo repository.

## What's in 4.0

- Secure boot anchored in the secure element (CYB-SEC-STD-014 SEC-01)
- OTA images signed by the Cyberdyne signing service (SEC-02, decision DEC-009)
- Mutual TLS to the Sirius consumer cloud (SEC-04)
